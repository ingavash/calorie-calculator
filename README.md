# CalorieFlow — Калькулятор калорій та макронутрієнтів на React

Сучасний веб-додаток на **React + Vite** для розрахунку добової норми калорій (за формулою Міффліна — Сан-Жеора), балансу макронутрієнтів (БЖВ) та ведення щоденника харчування.

## Можливості
- **Розрахунок BMR та TDEE** залежно від статі, віку, ваги, зросту та рівня фізичної активності.
- **Вибір цілі**: Схуднення (-18%), Підтримка ваги, Набір маси (+15%).
- **Контроль БЖВ**: Автоматичний розрахунок денної норми білків, жирів і вуглеводів із прогрес-барами.
- **Щоденник харчування**: Швидке додавання популярних продуктів в один клік або власних страв.
- **Збереження даних**: Усі дані автоматично зберігаються у `localStorage`.

## Запуск проєкту локально

```bash
npm install
npm run dev
```
